# About

I'm **0x3xploit** — a security researcher and reverse engineer focused on low-level systems, binary exploitation, and Windows internals.

This blog documents my research, CTF writeups, and notes on topics I find interesting:

- **Binary Exploitation** — stack overflows, heap exploitation, ROP chains, ASLR/NX bypass
- **Reverse Engineering** — static analysis, dynamic analysis, unpacking, anti-debug
- **Kernel Research** — Windows kernel internals, driver development, kernel exploitation
- **CTF Writeups** — challenges I've solved and techniques used

## Tools I Use

- `pwntools`, `pwndbg`, `gdb-peda` for exploit development  
- `IDA Pro`, `Ghidra`, `x64dbg` for reverse engineering  
- `WinDbg` for Windows kernel debugging  
- `Wireshark`, `frida` for dynamic analysis
